# tools/

*(Español: [README.es.md](README.es.md))*

**This folder is empty, and that is the point.**

The port is someone else's and has no license, so there is nothing of it to script around here
without redistributing it. What would go in a `tools/` folder — build and packaging — belongs to the
fork, and its instructions are the ones to follow.

What this repository adds is [`../docs/INSTALL.md`](../docs/INSTALL.md): the procedure, the identity
step, and the four console behaviours that look like a broken build.
